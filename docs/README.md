# Portfolio Documentation

Project documentation is organized into two areas:

- [Product](product/README.md): what the portfolio should communicate, who it serves, and how its content and sections should work.
- [Engineering](engineering/README.md): how the portfolio is designed, implemented, tested, deployed, and maintained.

Keep each document focused on one subject. Add new documents only when there is meaningful information to preserve.

Media capture specs, source images and recordings, and gallery selection live in
the [media workspace](../media/README.md). Finished website assets remain in
`public/`.
