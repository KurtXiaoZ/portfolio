# Individual Case Studies

Create one Markdown document in this directory for each planned case study. Use a short, descriptive filename such as `project-name.md`.

Each document should capture:

- working title and publication status
- why the project belongs in the portfolio
- intended audience takeaway
- verified project facts and available metrics
- Kurt's role and contribution
- proposed narrative and content outline
- available visuals or artifacts
- confidentiality constraints
- unresolved content questions

Use the [case-study page brief](../pages/case-study.md) for the shared presentation requirements.
