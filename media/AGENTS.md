# Media Generation Guidelines

Follow these guidelines when generating or editing portfolio images and
recordings. Keep project-specific requirements in the project's `spec.md`.

## Keep Visuals Clean

- Avoid redundant elements. Every heading, label, annotation, and decoration
  should contribute information or help the viewer understand the visual.
- Omit labels that repeat what is already clear from the content or surrounding
  page. For example, a recognizable checkout beside an interaction callout does
  not need additional “BRANDED CHECKOUT” and “CUSTOMER INTERACTION” headings.
- Use composition, spacing, and visual hierarchy to communicate relationships
  before adding explanatory text.
- Review images and representative video frames at their intended display size.
  Remove elements that add clutter without improving understanding.
